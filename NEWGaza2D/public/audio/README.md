# New Gaza 2D soundscape

Original sound effects generated specifically for the browser game.
No Unity or former 3D project audio is used.

- Excavator: diesel and hydraulic pump.
- Bulldozer: diesel and articulated track texture.
- Truck: moving diesel tipper.
- Rubble: concrete, gravel and bucket/bed contact.
- Construction: hand tools, mixing and scaffolding.
- Industry: conveyors and sorting machinery.
- Farm: foliage, birds and breeze.
- Neighborhood: quiet restored residential ambience.
- Coast: Mediterranean shore.
- Complete: original completion accent.

Loop clips are approximately six seconds, encoded at 64 kbps. Playback
normalizes their levels and crossfades loop boundaries once during decoding.
UI clicks are short, original Web Audio tones.

The requested television introduction is not included. Integrating it requires
an authorized audio file; these effects are not a substitute or a recreation.
