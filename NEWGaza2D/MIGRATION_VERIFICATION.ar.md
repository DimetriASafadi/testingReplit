# تحقق تهيئة مساحة العمل

## نطاق العمل الحالي

وجّه المستخدم بترك Unity في مجلده دون إضافة أو تعديل، والتركيز على نسخة 2D بالنظام الجديد. لذلك لا تُعدّ قيود فحوص Unity المذكورة أدناه عائقًا أو مطلبًا للويب، ولا يُطلب استعادة ملفاتها أو توليدها. التحقق التلقائي الحالي خاص بـ NEWGaza2D.

## ما تم التحقق منه

- مقارنة SHA-256 للملفات الأصلية مع `.migration-backup/`: مشروع Unity (677 ملفًا غير مولد)، الأدوات (49)، المرفقات (105)، الصادرات المحلية (17)، وحزم Python المحلية وملفاتها. لا اختلاف في محتوى أي ملف أصلي.
- وثيقتا NEWGaza2D الأصليتان وملفات Python الأصلية متطابقة مع النسخة الاحتياطية.
- نجح أمر `persistence-regressions`: الحفظ 85 تأكيدًا، الاقتصاد 6329 تأكيدًا، والبناء الحر 2784 تأكيدًا.
- نجح فحص واجهة النشاط المركّز:
  `dotnet run --project testingReplic/Tests/SourceChecks/SourceChecks.csproj --configuration Release -- --hud-activity-visibility`
  (32 حالة).
- نجحت اختبارات بروتوكول أدوات التجميع المحاكى (9 اختبارات):
  `python3 -m unittest discover -s tools/tests -p 'test_unity_compile.py'`.
- نجح فحص TypeScript للويب، وعمل workflow المعاينة. الصفحة الحالية تصريح بالتهيئة فقط، وليست لعبة.

## قيود سابقة للتهيئة وليست انحدارًا

أمر `native-source-and-movement` الأصلي محفوظ دون تغيير، لكنه لا يكتمل:

1. `SourceChecks` يتوقف لغياب `exports/housing-assets/Manifest.json`.
2. عند تشغيل `EquipmentTests` منفردًا، تنجح مجموعات أولية ثم يتوقف بسبب غياب `exports/models/Gaza-City-Production-Placement.json`.

أُعيد تشغيل الفحصين على المشروع داخل `.migration-backup/`، وظهرت المشكلة نفسها. هذان الملفان غير موجودين في النسخة الاحتياطية المحلية أو تاريخ Git المتاح لمساريهما. لم تُختلق بيانات بديلة، ولم يُغيّر أي اختبار لإخفاء الفشل. لإكمال الفحصين، يجب استعادة الصادرات الأصلية من نسخة محلية أو توليدها بالأدوات الأصلية في عمل منفصل.

كل الفحوص المذكورة هي فحوص مصادر ومنطق بعزل واجهات Unity. لم يُشغّل Unity Editor، ولم يُجرَ تجميع Unity أو Play Mode أو فحص جهاز.
