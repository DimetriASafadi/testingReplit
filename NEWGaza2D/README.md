# NEWGaza2D — لعبة إعادة إعمار غزة للمتصفح

هذا المجلد هو المنزل المستقل للنسخة الجديدة ثنائية الأبعاد. أبقِ كل ملفات اللعبة المستقبلية فيه: الشيفرة، الإعدادات، الاختبارات، والتوثيق وأصول اللعبة.

## الاتجاه المتفق عليه

- لعبة متصفح قابلة للعب والوصول للجمهور.
- Phaser مع TypeScript؛ المعاينة أثناء التطوير عبر Replit Preview.
- منظور خريطة علوي مائل (isometric/2.5D)، مع أحياء واضحة ومبانٍ تتدرج حالاتها بين الدمار والتنظيف والبناء والإعمار.
- أسلوب بصري شبه واقعي مستوحى من البيئة العمرانية في غزة: مبانٍ خرسانية متقاربة، أسطح مسطحة، خزانات مياه وشرفات وحطام وشوارع قابلة للقراءة.
- استلهام الصورة التصورية لحيّ كامل مدمر التي اختارها المستخدم. هي مرجع أسلوبي مولّد، وليست خريطة جغرافية أو توثيقًا لموقع بعينه.
- دعم الهاتف والمتصفح منذ التصميم؛ تقسيم الخريطة إلى مناطق حتى لا يلزم تحميل مدينة كاملة في البداية.

## تنظيم العمل لاحقًا

- اقرأ [ملاحظات المستخدم قبل بدء العمل](PRE_IMPLEMENTATION_NOTES.ar.md) قبل تصميم الأصول أو تنفيذ اللعبة؛ تتضمن اتجاهات الآليات، وجهي المباني، رسوم الإنشاء، واختيار المناطق.

- ضع تطبيق Phaser، وملفات `package.json` وأوامر تشغيله واختباراته داخل هذا المجلد.
- خصص داخله مجلدات للشيفرة والأصول؛ لا تنشئ ملفات اللعبة أو الأصول في جذر المستودع أو `testingReplic/Assets/`.
- فضّل أطالس رسوم متناسقة، ومباني قابلة لإعادة الاستخدام، وحالات تلف وإعمار مميزة بدل صورة كبيرة ثابتة للخريطة.
- استخدم رسومًا مصيّرة من نماذج متناسقة عند الحاجة إلى مظهر قريب من الصورة التصورية؛ يمكن تنفيذ الخريطة والحركة وتفاعل اللاعب كعناصر 2D داخل Phaser.

## الحالة

نسخة Phaser قابلة للعب في Preview. يبقى مشروع Unity في `testingReplic/` منفصلًا ولم تتغير ملفاته.

## التشغيل والاختبار

- المشغّل المُدار: `artifacts/new-gaza-2d: web`؛ يزود Vite بقيمتي `PORT` و`BASE_PATH`.
- اختبارات المنطق: `pnpm --filter @workspace/new-gaza-2d-game test`.
- فحص الأنواع: `pnpm --filter @workspace/new-gaza-2d-game typecheck`.
- بناء الإنتاج: `PORT=18578 BASE_PATH=/ pnpm --filter @workspace/new-gaza-2d-game build`.
- اختبارات المتصفح داخل `tests/browser-regression.mjs` و`tests/browser-touch.mjs` تستخدم Chromium مع منفذ تصحيح محلي 9222 وملف مستخدم مؤقت منفصل. لا تشغلها على متصفح اللاعب: تختبر الحفظ ببيانات اختبار وتقدم ساعة المتصفح فقط، دون اختصار مؤقتات اللعبة الحقيقية.

## أول تجربة

اختر الشجاعية، ثم قطعة نظيفة لبناء مصنع إعادة التدوير (١٥ ألف عملة، دقيقتان). بعد اكتماله اشترِ حفارًا وجرافة وشاحنة. اضغط الركام لإرسال الفريق؛ السفر مستقل عن دقيقة العمل وعن العودة. تصبح الأرض نظيفة عند انتهاء العمل، وتصل المواد عند عودة الفريق. بِع المواد من نافذتها ثم ابنِ واختر الأمام أو الخلف. مشاريع الحي التسعة لها متطلبات وأوقات حقيقية؛ الطريق الرئيسي يستغرق ١٨ ساعة.

## النطاق وحدود النسخة

- ١٣ منطقة متسلسلة، ٥٣ موقع ركام و١١ قطعة نظيفة بكل حي؛ تخطيط توضيحي للعب لا خريطة شوارع رسمية.
- كتالوج البناء والآليات والترقيات الفردية، أربعة أنواع مواد، الاستثمارات المتكررة والدخل الساعي، مشاريع البنية الأساسية والمكافآت.
- رسوم إيزومترية مولدة برمجيًا، ١٦ اتجاهًا للآليات، وجها المبنى وثلاث مراحل إنشاء، وخلفيتان فنيتان مولدتان. هذه نسخة فنية أولى وليست مطابقة فوتوغرافية للمراجع.
- الحفظ محلي في هذا المتصفح فقط، مع تصدير JSON وتحذير عند تلف الحفظ أو فشل الكتابة. لا مزامنة سحابية ولا استيراد من Unity ولا صوت حاليًا. التصدير نسخة أرشيفية؛ واجهة استيراده غير متاحة بعد.
- رصيد البداية مليون مرة واحدة. البناء بالمال فقط؛ بيع المواد يعادل تقريبًا ثلث سعر المبنى، بتقريب قيمة الناتج إلى مضاعفات عشر عملات كما في اقتصاد المصدر.
- فحوص المتصفح تحاكي الهاتف ولا تثبت أداء جهاز فعلي. اكتمال المسار الاقتصادي لا يعني نقل كل تفاصيل Unity.
