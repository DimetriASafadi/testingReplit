# مجسّمات الأشياء المدمّرة — نيو غزة

هذه الحزمة مخصّصة للأطلال والعناصر المدمّرة فقط، ومستوحاة من صور المستخدم. ليست توثيقًا لمبنى حقيقي أو مسحًا لحالة الدمار. لم تُنشأ في هذا العمل نسخ معمّرة، ولم تتغيّر المجسّمات الحالية للمشاريع المكتملة.

## المحتوى

- **13 طراز أطلال**: الشجاعية، التفاح، الشيخ رضوان، الدرج، الكرامة، البلدة القديمة، النصر، الصبرة، الزيتون، الرمال، تل الهوا، الشيخ عجلين، والرشيد.
- **8 عناصر إضافية**: مسجد، مدرسة، مبنى صحي، مبنى خدمات، جدار مكسور، مركبة محترقة، حفرة بحافة ركامية، وأنقاض خرسانة وطوب.
- ملفات **FBX** قابلة للتعديل، وخامات PNG وإحداثيات UV. وحدة التأليف متر، ونقطة الارتكاز في منتصف قاعدة المجسّم.
- الخامات والهيئات مُنشأة لهذه الحزمة؛ لم تُستخدم صور المراجع كخامات للمجسّمات.
- الحفرة مجسّم بصري ثابت، وليست نظام حفر ديناميكي لتضاريس اللعبة.

## أماكن الملفات

- ملفات FBX والخامة المستخدمة معها: `Assets/NewGaza/Art/DestroyedFBX/`.
- نسخ التشغيل: `Assets/NewGaza/Resources/Models/ruin_*.obj` والخامات `ruin_*_albedo.png`.
- اختيار الطراز بحسب معرّف الحي الثابت: `Assets/NewGaza/World/CityRuinProfiles.cs`.

تستخدم اللعبة نسخ OBJ المُصدّرة من المجسّمات نفسها، وفق مسار الاستيراد الحالي. ملفات FBX موجودة خارج Resources حتى لا تُحمّل اللعبة نسختين من المجسّم، ولا يعتمد الربط على GUID أو ملفات `.meta` من جهاز المؤلف.

## الدمج داخل اللعبة

المجسّم الأساسي للأطلال يختلف بحسب الحي: من سكن عائلي قصير إلى هيئات عمرانية أعلى ومبانٍ ساحلية. توجد استثناءات فنية مثل أقواس البلدة القديمة؛ هذه طرز فنية وليست ادعاءً بقياسات مبانٍ فعلية.

تستخدم مواقع الخدمات مجسّمات خدمية مهدّمة، وتُضاف تفاصيل صغيرة مدمّرة داخل حدود المواقع. كل ذلك داخل **مرحلة الموقع المدمّر فقط**:

1. الموقع مدمّر: طراز أطلال الحي أو المبنى الخدمي المدمّر، مع تفاصيل وركام.
2. أُزيل الركام: يظهر الموقع المُجهّز الحالي، لا الأطلال الجديدة.
3. بدأ البناء: يظهر البناء الجاري الحالي.
4. اكتمل المشروع: يظهر المجسّم المكتمل الحالي.

لم تتغيّر بيانات الحفظ، الاستحقاقات، المال، تكاليف المشاريع، أوقات البناء، أعمال المعدات أو الطرق. هدف جمع الركام وحالته المحفوظة بقيَا كما هما.

## الاستيراد في Unity

افتح المشروع الأصلي `testingReplic` في Unity، ثم استخدم:

1. `New Gaza/Prepare imported city models` لتطبيق قابلية قراءة الشبكات وإعدادات الخامات.
2. `New Gaza/Open game scene` ثم Play.

**لا تحتوي الملفات الجديدة على `.meta`**؛ دع Unity على جهازك ينشئها.

## التحقق وإعادة الإنتاج

```sh
dotnet run --project testingReplic/Tests/DestroyedAssets/DestroyedAssets.csproj --configuration Release
dotnet run --project testingReplic/Tests/SourceChecks/SourceChecks.csproj --configuration Release
dotnet run --project testingReplic/Tests/Domain/DomainTests.csproj --configuration Release
blender --background --factory-startup --python tools/generate_destroyed_assets.py
blender --background --factory-startup --python tools/render_destroyed_assets.py
python tools/compose_destroyed_previews.py
```

صور المعاينة تُرسم من ملفات FBX المُسلَّمة باستخدام Blender Cycles على المعالج. **ليست لقطات من Unity أو الهاتف**. فحص الملفات وصياغة المصدر لا يعادل تشغيل Unity أو قياس الأداء على جهاز؛ يحتاج الاستيراد النهائي والمظهر واللمس والأداء إلى اختبار داخل Unity وعلى الهاتف.
