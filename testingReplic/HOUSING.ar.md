# مباني نيو غزة ومراحل البناء

## المرجع والتصميم

هذه أصول أصلية مستوحاة من صورة أشكال المباني السكنية التي قدّمها المستخدم، وليست مسحًا فوتوغرافيًا أو نسخًا من مبانٍ محددة. تستخدم اللياسة العاجية والحجر الرملي الدافئ والقرميد، والزجاج الأزرق الداكن، والشرفات والأسطح المحاطة بالدرابزين. أُعدت للعرض الإيزومتري في لعبة الهاتف.

تحتوي الحزمة على **عشرة نماذج × أربعة أشكال = أربعين ملف FBX**:

1. منزل صغير بسقف قرميدي.
2. منزل عائلي متوسط.
3. فيلا سكنية حديثة.
4. عمارة بشرفات وأربعة طوابق.
5. عمارة بشرفات وستة طوابق.
6. مجمع سكني.
7. عمارة حديثة بواجهات زجاجية.
8. عمارة حجرية تقليدية بأقواس.
9. برج سكني من اثني عشر طابقًا.
10. فيلا ساحلية ببركة سباحة.

## الأشكال الأربعة

- **`foundation` — التأسيس:** أعمال أرضية وقواعد وحديد تسليح، دون واجهات مكتملة.
- **`frame` — الهيكل والبناء:** أعمدة وبلاطات خرسانية نظيفة؛ ليست أنقاضًا مكسورة.
- **`finishing` — التشطيب:** حوائط غير مكتملة، وواجهات في طور التشطيب، وسقالات وتفاصيل الورشة.
- **`final` — المكتمل:** الواجهات والشرفات والنوافذ والأسطح والحدائق النهائية، دون سقالات الإنشاء.

يرتبط تبديل هذه الأشكال بتقدم مشروع السكن القائم فعلًا. لا تُنشأ أربعة مشاريع اقتصادية منفصلة، ولا تُغيَّر مدد البناء أو الموارد أو مخطط الحفظ. عند استعادة مشروع مكتمل بعد غياب اللاعب، يظهر الشكل النهائي مباشرةً. الأطلال السابقة محفوظة كمرحلة منفصلة تسبق التأسيس.

يحافظ اختيار السكن على هوية الحي: السكن العائلي شرقًا، والمباني الحضرية الأعلى غربًا، والطابع الحجري في البلدة القديمة، والمباني الساحلية قرب الساحل. تظل المشاريع غير السكنية بأشكالها المتخصصة الحالية.

## الأشخاص أثناء العمل

العمّال شخصيات ثلاثية الأبعاد صغيرة داخل اللعبة، وليست رموزًا أو صورًا. يتحركون حول محيط الموقع، وتختلف أدواتهم وحركاتهم بين التأسيس، والبناء، والتشطيب. لا يظهرون في المواقع غير المبدوءة أو الأحياء المقفلة، ويختفون عند اكتمال المشروع.

حركة العمّال إجرائية يقودها مصدر Unity، وليست مقاطع بشرية مضمنة داخل ملفات FBX الخاصة بالمباني. تُسلَّم أشكال المباني ثابتة وقابلة للتحرير، مع منطق تبديلها وتحريك العمّال ضمن مشروع اللعبة.

تتضمن الحزمة أيضًا معاينة GIF لحركة العمّال: تُرسم مباشرةً من عينات هندسة مصدر اللعبة أثناء تشغيل فحص مستقل. ليست تسجيلًا لمشهد Unity، ولا تحتوي على مبنى مرسوم بدل المشهد الحقيقي.

## الاستيراد والملفات

- ملفات التحرير: `Assets/NewGaza/Art/HousingFBX`.
- ملفات العرض التي تحملها اللعبة: `Assets/NewGaza/Resources/Models`؛ نموذج OBJ وخامة وبيانات لكل شكل.
- بيانات الأبعاد وعدد المثلثات: `exports/housing-assets/Manifest.json`.
- المعاينات: صور من ملفات FBX المصدّرة بعد إعادة استيرادها في Blender، وليست لقطات من Unity.

لا تضف نسخًا ثانية من ملفات FBX إلى `Resources`؛ اللعبة تستخدم مواردها الأصلية. لا تُرفق ملفات `.meta` جديدة؛ يولّدها Unity محليًا.

أرشيف المصدر الكامل متاح في بطاقة التحميل. ولتجاوز حد حجم طلب الرفع، يُحفظ في GitHub على جزأين مع بيانات التحقق. بعد سحب المستودع، يعيد الأمر `python tools/join_unity_source.py` تجميع الأرشيف الأصلي ويتحقق من بصمته؛ ويمكن أيضًا العمل مباشرةً داخل مجلد `testingReplic` دون تجميعه.

## إعادة الإنتاج والفحص

من جذر المستودع، باستخدام Blender 4.4 أو أحدث:

```bash
blender --background --threads 2 --python-exit-code 1 --python tools/generate_housing_assets.py --
blender --background --threads 2 --python-exit-code 1 --python tools/render_housing_assets.py --
python tools/compose_housing_previews.py
python tools/package_housing_assets.py
python tools/package_unity_source.py
```

الفحوص المستقلة:

```bash
dotnet run --project testingReplic/Tests/Construction/ConstructionTests.csproj --configuration Release
dotnet run --project testingReplic/Tests/ConstructionCrew/ConstructionCrewTests.csproj --configuration Release
dotnet run --project testingReplic/Tests/SourceChecks/SourceChecks.csproj --configuration Release
```

الفحوص المستقلة لا تساوي ترجمة Unity أو اختبار Play أو قياس أداء الهاتف. يجب إجراء هذه الاختبارات داخل Unity على الجهاز المستهدف قبل الاعتماد على الأداء أو إصدار نسخة متجر.
