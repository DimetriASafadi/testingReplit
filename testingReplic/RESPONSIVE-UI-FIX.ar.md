# إصلاح نوافذ الواجهة والتحجيم في Unity

الحزمة تحديث مصدر فوق المشروع الحالي، وليست مشروع ويب أو APK. تشمل أيضًا إصلاحي الكاميرا والحفظ السابقين.

## التثبيت

أوقف Play، وفك الحزمة داخل مجلد المشروع الذي يحتوي `Assets`. ادمج المجلدات واستبدل الملفات المرفقة، بما فيها الملفات الجديدة `InterfaceViewport.cs` و`CityUiLayout.cs`. احتفظ بملفات `.meta` الموجودة، واترك Unity ينشئ ملفات `.meta` الجديدة. لا تحذف الحفظ.

## النوافذ

- **الصفحات**: عنوان يبدأ بـ «صفحة»، خلفية معتمة، زر «إغلاق» ثابت أعلى الصفحة، ومحتوى طويل قابل للتمرير.
- **حوار التأكيد**: لون مميز ونص «حوار تأكيد»، زر إغلاق أعلى الحوار، وتأكيد/إلغاء أسفله؛ الإلغاء أو الإغلاق لا ينفذ العملية.
- **تفاصيل الموقع أو المبنى ووضع البناء**: عنوان يوضح نوع اللوحة وزر إغلاق في أعلاها؛ إلغاء وضع البناء يزيل المعاينة دون إلغاء أعمال مشتراة أو حذف التقدم.
- **احتياجات الحي**: تظهر عند الضغط على زر «احتياجات الحي»، ويمكن إغلاقها.
- **الدليل والإشعارات والرئيسية**: لها أزرار إغلاق صريحة. يمكن إعادة إظهار الدليل من الإعدادات.

لا يُفتح المتجر فوق صفحة أخرى، ولا تتقدم ترويسة الرئيسية فوق أزرار حوار أو صفحة مفتوحة. زر Escape يغلق الحوار، ثم المتجر أو الصفحة أو تفاصيل الموقع حسب النافذة المفتوحة. يبقى إفلات المؤشر بعد الإغلاق محجوبًا عن المدينة لفترة قصيرة لمنع نقرة عرضية.

## التحجيم

كانت واجهة البناء تستخدم بكسلات الشاشة مباشرة، بينما يستخدم HUD أبعاد Canvas محجمة. الآن يستخدم الاثنان سياسة موحدة لحساب التحجيم والمنطقة الآمنة، ويُعاد تطبيقها عند تغيير حجم Game View أو الاتجاه. تُترك أحجام الصفحات الكبيرة مقيدة بالمنطقة الآمنة، مع تمرير المحتوى بدلاً من دفع أزرار الإغلاق خارج الشاشة.

تُحافظ السياسة على مساحة منطقية مناسبة للاتجاه، ثم تحجمها داخل المنطقة الآمنة الفعلية. قد تصبح الواجهة صغيرة في نافذة Game View صغيرة جدًا؛ هذا ليس اختبارًا لحجم اللمس الفعلي أو جودة الخط على كل جهاز.

## التحقق وحدوده

تغطي الاختبارات الحسابية أحجام 1601×733، 1920×1080، 800×600، 320×240، 390×844، 1080×1920، 2560×1080، 720×1280، والمربع، مع هوامش آمنة وبدونها. تُفحص حدود الترويسة والملاحة والمتجر والصفحات والحوار وتفاصيل المواقع والحي والدليل، ضمن الشاشة والمنطقة الآمنة.

فحوص المصدر تؤكد ربط أزرار الإغلاق والتحجيم المشترك ومسارات الرجوع والتداخل. لا تثبت هذه الاختبارات رسم Unity الحقيقي أو ترتيب EventSystem الفعلي؛ المحرر غير متاح هنا. عند التجربة على جهازك، غيّر Game View بين الاتجاهين وافتح/أغلق الرئيسية والإعدادات والمتجر والتأكيد وتفاصيل موقع، وتأكد من بقاء الإغلاق متاحًا ومن عدم تنفيذ شراء عند الإلغاء.
