# تشغيل «نيو غزة»

## افتح المشروع الصحيح

1. استعمل **Unity 6000.3.18f1** عبر Unity Hub.
2. أضف المجلد `testingReplic` الذي يحتوي مباشرةً على `Assets` و`Packages` و`ProjectSettings`.
3. انتظر اكتمال استيراد الحزم والملفات.
4. اختر من شريط القوائم **New Gaza → Apply mobile settings** مرة واحدة. وافق على إعادة تشغيل Unity إذا طُلب ذلك لتفعيل Input System.
5. اختر **New Gaza → Open game scene**.
6. اضغط **Play**. المدينة تُنشأ وقت التشغيل؛ وجود كائن إعداد واحد في المشهد قبل Play أمر مقصود.

المشهد هو `Assets/NewGaza/Scenes/NewGaza.unity`، وليس مشهد السباق القديم.

> الملفات داخل هذه النسخة لا تحدّث تلقائيًا نسخة أخرى من المشروع على جهازك. انقل المشروع كاملًا مع ملفات `.meta` أو حدّث نسخة Git المحلية.
> لا تغيّر اسم ملف C# وحده، ولا تنشئ نسخة ثانية من نفس الصنف. أسماء الملفات وأسماء أصناف MonoBehaviour مترابطة.
> إذا ظهر مسار قديم مثل `Assets/Script/ArcadeRaceGamee.cs` في خطأ، فأنت ما زلت تشغّل نسخة محلية مختلفة أو مشهد السباق.

## أول خمس خطوات داخل اللعبة

1. افتح الأسطول واشتر مصنع التدوير وحفارة وجرافة وشاحنتين: المجموع 40,000 من رصيد 50,000.
2. حدّد الركام ثم نفّذ عقد إزالة ونقل وتدوير. المعدات تعمل تلقائيًا.
3. راقب مراحل العقد ومخزون المواد، ثم بع ما تحتاجه من المخزون.
4. افتح المشاريع وابدأ مزرعة، أو وفّر المواد والرصيد لتنفيذ البنية التحتية والمنازل.
5. أكمل جميع متطلبات الحي ثم استلم مكافأته لفتح التالي.

المدة المعروضة حقيقية، وليست مؤقتًا تجريبيًا سريعًا. يستمر حساب الوقت أثناء إغلاق اللعبة. لا توجد أزرار غش أو تقديم وقت في واجهة اللاعب.

## التحكم على الهاتف

نقرة للتحديد، وضغط مطوّل للتفاصيل. نقرة ثانية على الركام تبدأ العمل، وعلى استثمار جاهز تجمع العائد.
شراء المشروع يحتاج تأكيدًا من الواجهة. السحب بإصبع يحرك الخريطة، وإصبعان للتقريب والدوران.
تدعم الواجهة مساحة الشاشة الآمنة والوضعين الطولي والعرضي، لكن يلزم اختبار فعلي للأجهزة قبل الإصدار.

## الحفظ والتصدير

الحفظ في `Application.persistentDataPath/new-gaza.json`، ومعه نسخة `.bak`.
القائمة **New Gaza → Open save folder** تفتح مكانه في المحرر.
لا تنقل هذا الملف إلى `Assets` ولا تضع بيانات لاعب حقيقية في مستودع Git.
عند تلف الحفظ تُجرّب النسخة الاحتياطية مع تنبيه؛ إن تعذر استرجاعهما تظهر رسالة خطأ بدل محو التقدم.

بعد إكمال الرشيد يمكنك عرض المدينة وتصوير الإنجاز. تحفظ الصورة داخل مجلد بيانات اللعبة ويظهر مسارها في Console.
الإرسال إلى معرض الصور والمشاركة الأصلية وتسجيل الفيديو ليست مدمجة بعد.

## تجهيز بناء محلي

- Android: ثبّت Android Build Support وSDK/NDK عبر Unity Hub، طبّق إعدادات الهاتف ثم افتح Build Profiles واختر Android. الإعداد المقترح IL2CPP وARM64 وAPI 26 كحد أدنى.
- iOS: ثبّت iOS Build Support، ثم أنشئ مشروع Xcode وأكمل التوقيع على macOS. الحد الأدنى المقترح iOS 15.
- اختر معرّف الحزمة وشهادات التوقيع الخاصة بك. لا تضع الشهادات أو كلمات المرور في المشروع.
- اللعبة الجديدة وحدها مفعّلة في قائمة مشاهد البناء، وتجربة السباق محفوظة على القرص.
- إعدادات الهاتف نقطة بداية وليست ضمان توافق أو اعتماد متجر.

## اختبارات مستقلة عن المحرر

من المجلد الأب:

```sh
dotnet run --project testingReplic/Tests/Domain/DomainTests.csproj --configuration Release
dotnet run --project testingReplic/Tests/SourceChecks/SourceChecks.csproj --configuration Release
```

الأول يختبر الاقتصاد والتقدم والحفظ المنطقي، والثاني يفحص صياغة C# والعربية.
لا يدعي أي منهما تجميع Unity أو تشغيل الفيزياء/الرسومات.

## قائمة قبول داخل Unity وعلى الهاتف

ابدأ بـ **New Gaza → Run play mode smoke test** لفحص بدء المشهد والكاميرا والواجهة والمحددات والخط والحفظ داخل محرر Unity الحقيقي. لا يغيّر الاختبار الرصيد أو يمحو التقدم.
هذا الفحص أُضيف إلى المشروع، لكنه لم يُشغّل في هذه البيئة التي لا تحتوي محرر Unity.

- لا أخطاء حمراء في Console عند فتح المشهد أو بدء Play.
- تظهر المدينة والواجهة العربية المتصلة، والأرقام بالترتيب الصحيح.
- يعمل الشراء بتأكيد ولا يتكرر عند الضغط السريع.
- النقر والسحب داخل القوائم لا يحركان الخريطة خلفها.
- يمكن التحريك والتقريب والدوران دون تنفيذ أمر بالخطأ عند رفع إصبع بعد حركة إصبعين.
- أكمل عقد تدوير، بع جزءًا من المخزون، وابدأ مشروعًا.
- اخرج وأعد فتح اللعبة: الرصيد والمخزون محفوظان، ومؤقت المشروع لا يعاد من البداية.
- الهدية لا تُستلم مرتين خلال 24 ساعة.
- الحي المقفل لا يقبل مشروعًا أو عقدًا. لا يفتح الحي التالي قبل إنجاز 100% واستلام المكافأة.
- راقب الإطارات والذاكرة والحرارة على هاتف متوسط، وعلى شاشة صغيرة ذات ثقب/نتوء.
- اختبر الإيقاف بالخلفية، وانقطاع الكتابة، ومساحة التخزين الممتلئة قبل أي إصدار للمتجر.
