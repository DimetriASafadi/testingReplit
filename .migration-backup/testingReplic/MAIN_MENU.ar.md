# واجهة نيو غزة الرئيسية

واجهة Unity أصلية وليست موقعًا أو صورة واجهة ثابتة. تُفتح عند تشغيل اللعبة ويمكن العودة إليها من زر «الرئيسية» أثناء اللعب. دمج التحديث لا يغيّر جغرافية الخريطة أو بيانات الحفظ أو شروط فتح الأحياء.

## ما تم ربطه

- خلفية مدينة اللعبة الفعلية؛ تظل حركة الآليات والتقدم مرتبطة بالمحاكاة والعمل الحقيقي.
- شريط علوي ثابت عند فتح القوائم من الرئيسية: اسم اللاعب والإعدادات، العملات، الخرسانة، الحديد، الخشب، مواد أخرى. الضغط على الموارد يفتح المخزن.
- قائمة جانبية: المدينة، الخريطة، المصنع، المكافآت، الإحصائيات، المعدات.
- خمس بطاقات: المخزن، المعدات، تأهيل الطرق، المتجر، صندوق الهدايا. تتحول إلى صف قابل للسحب عندما لا تتسع الشاشة.
- «ابدأ إعادة الإعمار»: يستأنف إزالة الركام النشطة، ثم آخر مبنى/مشروع جارٍ داخل حي مفتوح، ثم الحي المختار غير المستكمل أو أول حي مفتوح لم تُستلم مكافأته.
- بطاقة الحي: معاينة ثلاثية الأبعاد حقيقية بكاميرا مصغّرة، نسبة الإنجاز من الاقتصاد، مواقع الركام المنظّفة، المباني المكتملة والجارية، والاحتياجات الإقليمية.
- زر مكافأة الحي يظهر فقط عند استحقاقها ويستخدم إجراء الاستلام الحالي؛ لا تُفتح الأحياء أو تُمنح العملات من الواجهة مباشرة.
- تنبيه الهدية يعتمد على مهلة ٢٤ ساعة الفعلية، وليس علامة إشعار ثابتة.
- المصنع وترقية المعدات وشراؤها من صفحة الأسطول الحالية، وبيع الموارد من المخزن الحالي، والمباني من المتجر الحالي.
- «تأهيل الطرق» يعيدك للحي المستأنف لاختيار قطعة طريق فعلية؛ لا يبدأ عملاً وهميًا.
- ألوان القوائم والمتجر متناسقة مع الرئيسية: الأزرق الداكن والملكي والفاتح والذهبي، مع الأزرار البرتقالية والخضراء المناسبة.
- خطوط Cairo/Tajawal/Roboto الحالية واتجاه العربية محفوظة؛ الأيقونات أصلية مولّدة دون علامات شركات.

## ما لم يُضَف

لا مستوى لاعب، خبرة، وقود، رسائل، أصدقاء، صورة حساب حقيقية، أزرار موارد مجانية، بيع معدات أو تسجيل فيديو. هذه الميزات غير موجودة في المنطق الحالي. تبقى مكافأة الحي إجراء استلام فعليًا وليس منحة تلقائية جديدة. الأحياء السابقة تبقى متاحة وفق حالة الحفظ الحالية.

## الأداء والشاشات

تعتمد الواجهة على منطقة الشاشة الآمنة مع ترتيب أفقي/عمودي. صور الأزرار مجمّعة في أطلس واحد. تُحدَّث صورة الحي بدقة 384×216 كل ست ثوانٍ أو عند تغيّر الحي، ولا تُعاد محاكاة المدينة. لا يُضاف AudioListener آخر، ولا تتوقف أعمال البناء عند فتح الرئيسية.

## التحقق

اختبارات الإسقاط والتحويل والاستئناف والاستحقاق ضمن:

```
dotnet run --project testingReplic/Tests/Development/DevelopmentTests.csproj --configuration Release
dotnet run --project testingReplic/Tests/SourceChecks/SourceChecks.csproj --configuration Release
```

Unity غير متاح في بيئة التنفيذ؛ نجاح هذه الاختبارات ليس تأكيدًا لتجميع Unity أو عرض الواجهة على الهاتف. افحص Play في Unity: فتح الرئيسية، استئناف العمل، فتح وإغلاق النوافذ تحت شريط الموارد، العودة للرئيسية، المتجر، مكافأة حي مكتمل، توقيت الهدية، تغيير الاتجاه والمنطقة الآمنة.

المعاينة المرفقة إن وُجدت تصور توضيحي بالأيقونات والخطوط المرسلة وليست لقطة Unity. لا توجد ملفات `.meta` جديدة؛ اترك Unity يولّدها على جهازك دون حذف القديمة.
