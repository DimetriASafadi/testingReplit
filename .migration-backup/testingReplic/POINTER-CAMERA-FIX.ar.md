# إصلاح Screen position out of view frustum

الحزمة إصلاح Unity فوق مشروعك الحالي، وتشمل إصلاح `Invalid saved camera` السابق.

أوقف Play وفك الحزمة داخل مجلد المشروع الذي يحتوي `Assets`، مع استبدال الملفات المرفقة فقط. احتفظ بملفات `.meta` الموجودة وبملفات الحفظ؛ لا تتضمن الحزمة ملفات `.meta` جديدة.

## التغيير

- لا تُحوّل قيم موضع المؤشر `NaN` أو `Infinity` أو المواضع خارج نافذة عرض الكاميرا إلى أشعة كاميرا.
- يستخدم تظليل الحي عند مرور المؤشر نفس مسار التحويل المحمي، بدلاً من استدعاء `Camera.main.ScreenPointToRay` مباشرة كل إطار.
- عند فقدان تركيز التطبيق أو خروج المؤشر أو وجود لمسة غير صالحة، تُلغى حركة السحب الجارية دون نقرة أو اختيار بناء في آخر موضع صالح.
- تُتجاهل قيم تمرير العجلة ودوران الفأرة غير الصالحة. يعود التحكم المعتاد عند رجوع موضع صالح.
- لا يغيّر إصلاح الإدخال الرصيد أو المباني أو التقدم أو مؤقتات العمل.

## الاختبارات

اختبارات قيم موضع المؤشر تشمل الحالة الواردة في صورة الخطأ (`inf, -inf`)، وحدود النافذة والنافذة ذات الحجم الصفري والنافذة ذات الموضع المزاح. فحوص المصدر تؤكد أن جميع استدعاءات أشعة الشاشة محمية قبل الاستدعاء. هذه ليست تجربة إدخال حقيقية داخل Unity؛ المحرر غير متاح هنا.

بعد الاستيراد، امسح رسائل Console القديمة ثم جرّب الخروج بالمؤشر من Game view والعودة إليه، وتبديل النافذة، والسحب والاختيار وتحديد موقع مصنع. يجب ألا تظهر رسائل إسقاط المؤشر غير الصالح مجددًا.
